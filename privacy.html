개인정보처리방침

시행일 2026년 9월 30일

오나무 업로드 도구(이하 “오나무”)는 유튜브 채널 오나무(@5NaMu) 운영자가 자기 채널에 쇼츠 영상을 자동으로 올리기 위해 만든 개인용 도구입니다. 운영자 본인의 구글 계정 한 개만 이 도구에 로그인하며, 다른 사람의 개인정보는 수집하지 않습니다.

  1. 요청하는 Google 권한

    운영자 본인이 로그인할 때 아래 권한을 요청합니다.

    • youtube.upload, youtube: 운영자 채널에 영상을 올리고, 제목·설명·썸네일·재생목록을 설정합니다.
    • drive.file: 운영자 구글 드라이브의 “오나무 쇼츠” 폴더에 완성 영상 사본을 저장합니다. 이 도구가 만든 파일에만 접근할 수 있습니다.

  2. YouTube API 서비스 이용

    이 도구는 YouTube API 서비스를 사용해 운영자 채널에 영상을 올립니다. 이 도구를 사용하는 것은 YouTube 서비스 약관에 동의하는 것이며, 관련 정보 처리에는 Google 개인정보처리방침이 함께 적용됩니다.

  3. 수집하지 않는 정보

    시청자, 구독자, 댓글 작성자 등 다른 사용자의 정보는 수집·저장·열람하지 않습니다. 운영자 계정의 메일, 연락처, 시청 기록 등 업로드와 관계없는 데이터도 읽지 않습니다.

  4. 인증 정보의 보관

    로그인 후 발급되는 인증 토큰은 운영자의 GitHub 저장소 암호화 비밀값(Secrets)에만 보관되며, 영상 제작 작업이 실행될 때만 사용됩니다. 토큰은 공개되거나 다른 곳으로 전송되지 않습니다.

  5. 제3자 제공

    Google API로 얻은 어떤 정보도 판매하거나 제3자에게 제공하지 않으며, 광고나 분석에 사용하지 않습니다. 이 도구의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책과 제한적 사용(Limited Use) 요구 사항을 따릅니다.

  6. 권한 철회

    언제든 Google 계정의 연결된 앱 페이지 또는 Google 보안 설정의 앱 권한 페이지에서 오나무의 접근 권한을 삭제할 수 있습니다. 삭제하면 이 도구는 더 이상 채널이나 드라이브에 접근하지 못하며, 운영자는 GitHub에 보관된 토큰도 함께 삭제합니다. 이 도구는 인증 토큰 외에 Google API로 받은 데이터를 따로 저장하지 않습니다.

English summary

The 오나무 upload tool is a private, single-user tool that uploads short videos to the owner's own YouTube channel, 오나무 (@5NaMu). Only the channel owner's Google account signs in.

  • Scopes: youtube.upload and youtube to upload videos to the owner's channel and set title, description, thumbnail and playlist; drive.file to save a copy of each finished video in a folder the tool creates in the owner's Google Drive.
  • YouTube API Services: this tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. The Google Privacy Policy also applies.
  • Data: no data about viewers, subscribers, commenters or other users is collected, stored or shared. No Google user data is sold, shared with third parties, or used for advertising or analytics. Use of Google user data follows the Google API Services User Data Policy, including the Limited Use requirements.
  • Storage: the OAuth refresh token is stored only as an encrypted GitHub Actions secret and used only while a video job runs. No other API data is stored.
  • Revoking access: access can be revoked at any time at Google security settings; the stored token is then deleted.
